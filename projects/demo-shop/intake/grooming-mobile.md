# Grooming notes: shopping on an Android phone

Session: grooming for shoppers using the Demo Shop page in Chrome on Android phones. Attendees: product owner, frontend developer, QA Lead. The page and its texts are the ones already agreed for the web; this session covers only what is different on a phone.

## What we agreed

- Shoppers use Chrome on Android phones, held upright or turned sideways.
- Upright, the Products and Cart sections stack in one column and the page never scrolls sideways.
- Turned sideways, everything still works; the sections may sit side by side when there is room.
- Every button and quantity field must be easy to tap: at least 48 by 48 density-independent pixels, as Android's accessibility guidance recommends.
- Tapping a quantity field opens the number pad, not the full text keyboard.
- Adding, removing, the total and the error messages behave exactly as on the web page, with the same texts.

## Parked

- A native Android app.
- Tablets.

## Things nobody decided

- Which Android and Chrome versions are the minimum.
- Whether the page must work with the phone's system font size turned up.
