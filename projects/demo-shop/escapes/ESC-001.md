# Script in a product name ran on the shopping page

A catalogue editor renamed a product to `Notebook <img src=x onerror=alert(1)>`. Shoppers who opened the page saw an alert box; the name was interpreted as markup instead of shown as text.

## What was released

- PRD-CART-UI EC-002.2 says product names are shown as plain text and markup is never interpreted.
- Case WEB-CART-07 covers EC-002.2 but was marked manual, because the fixed test catalogue has no product name with markup. No person ran it before release.
- The page built product and cart rows with `innerHTML`, and the server sent no Content-Security-Policy.
- Release RUN-2026-0925-017 was approved with risks; the blind review listed WEB-CART-07 as not executed.

## Not known

- How long the renamed product was live.
- Whether any shopper's session was affected beyond the alert.
